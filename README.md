# OPSD Distillation Extensions (PCT)

This repository contains the OPSD distillation/PCT extension files extracted from the
OPSD tree, focused on experiment protocol, transport losses, strict validation,
and report generation.

Core docs:

- `PCT_EXPERIMENTS.md`: full experiment protocol and matrix generation flow.
- `PCT_STATUS.md`: local smoke/checklist status with completed milestones.
- `configs/pct_neurips_spec.json`: paper-grade contract for required artifacts.

Use this directory with the full OPSD runtime if you need to run all experiments end-to-end.
